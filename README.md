# Stargate × Cyberpunk 2077 — kapitoly

> **Neoficiální nekomerční fanouškovský projekt.** Projekt není spojen se společnostmi CD PROJEKT RED, Amazon MGM Studios ani dalšími držiteli práv a není jimi schválen, sponzorován ani podporován. Práva k původním světům, postavám, názvům a ochranným známkám náleží příslušným držitelům. Naše tvorba je zdarma, bez prodeje a placeného přístupu. Toto prohlášení nepředstavuje licenci ani svolení držitelů práv.

Co by vzniklo, kdyby se potkaly světy Stargate a Cyberpunku? Tady sdílíme rozpracovaný příběh a zveme další fanoušky ke společnému vymýšlení. Text se průběžně mění; pracovní verze nejsou hotová kniha.

## Zapoj se

Můžeš přinést nápad, napsat dialog nebo scénu, navrhnout osnovu nebo dát zpětnou vazbu. Nemusíš umět Git: [vyber si šablonu návrhu](https://github.com/jiriburda01/cyberpunk-kapitoly/issues/new/choose) a napiš vlastními slovy, co tě napadlo.

Konkrétní změny textů posílej jako pull request. O zařazení do společného příběhu rozhoduje **@jiriburda01**. Nápad ani alternativní scéna se automaticky nestávají kánonem. Podrobnosti najdeš v [návodu pro přispěvatele](CONTRIBUTING.md).

Tento repozitář obsahuje pouze zveřejněné kapitoly a pravidla spolupráce. Pracovní podklady, obrazové reference a soukromá historie se sem nepřenášejí. Další kapitoly a aktualizace zveřejňuje správce po výběru; nejde o automatické zrcadlo pracovního projektu.

Při tvorbě respektujeme [pravidla fanouškovské tvorby CD PROJEKT RED](https://www.cdprojektred.com/en/fan-content); ta nenahrazují svolení ostatních držitelů práv.
