# Jak se zapojit

Vítáme nápady, dialogy, scény, osnovy i připomínky ke světům Stargate a Cyberpunk. Projekt je neoficiální a nekomerční, bez prodeje a placeného přístupu.

## Nápad bez Gitu

V záložce Issues vyber New issue a šablonu Nápad, Dialog nebo scéna, Osnova nebo Připomínka. Vyplň ji vlastními slovy. Popiš, ke které kapitole návrh patří a jestli mění dosavadní příběh. Pro vytvoření návrhu potřebuješ účet GitHub, pozvání do veřejného repozitáře není nutné.

## Úprava kapitoly

1. Přečti si README a související kapitoly v `05_KAPITOLY`.
2. Vytvoř si fork (vlastní kopii tohoto veřejného repozitáře) a v něm větev pro svůj návrh. Úpravy lze dělat také přes web GitHubu.
3. Uprav kapitolu nebo přidej novou navrhovanou scénu do `05_KAPITOLY`. Alternativu jasně označ.
4. Otevři pull request z vlastní větve do větve `main` tohoto repozitáře a vyplň šablonu. Jeden návrh drž u jednoho tématu.
5. Počkej na posouzení od **@jiriburda01** a zapracuj případné připomínky. Návrhy zatím slučuje správce projektu.

Nemusíš se učit Git předem. Pokud si nevíš rady, vlož text do issue a správce pomůže se zařazením.

## Společná pravidla

- Nápad se stává součástí příběhu až po schválení a začlenění správcem.
- U změn popiš motivaci postav a dopad na návaznost děje. Alternativní scény jsou vítané.
- Kritizuj konkrétní text, ne autora. Vysvětli důvod a pokud možno navrhni řešení.
- Zachovávej uvedení autorství a větší přepracování probírej s přispěvatelem.
- Přispívej vlastní tvorbou nebo materiály, k jejichž sdílení máš oprávnění. Cizí obrázky a další reference raději odkazuj; nenahrávej celé knihy, scénáře, hudbu ani herní soubory.
- Nepřidávej soukromé kontakty ani neveřejné pracovní podklady. Příspěvky i komentáře jsou veřejné.

Soubor `.github/CODEOWNERS` určuje správce jako recenzenta. Povinné schválení se vynucuje samostatným pravidlem ochrany větve na GitHubu.
